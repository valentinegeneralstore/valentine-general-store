# VALENTINE GENERAL STORE

Bienvenue chez Valentine General Store.

Boutique en ligne marocaine proposant une sélection de vêtements,
accessoires, montres et produits inspirés du style vintage et western.

## Fonctionnalités

- Catalogue de produits
- Filtres par catégorie
- Commande en ligne
- Paiement à la livraison
- Enregistrement des commandes dans Supabase
- Tableau de bord administrateur sécurisé
- Gestion du statut des commandes

## Technologies

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages

## Administration

La page d'administration est disponible à :

`/admin.html`

L'accès aux commandes nécessite le compte administrateur
créé dans Supabase Authentication.

## Statuts des commandes

- Nouvelle
- Confirmée
- Expédiée
- Livrée
- Annulée
